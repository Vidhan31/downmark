# Project instructions

## Core goal

A fully native, simple, and fast Markdown viewer and editor using GPUI and GPUI-Kit.

## External documentation

- The frameworks and libraries used in this project postdate model knowledge cutoffs. Do not guess or assume behavior. Verify details against official documentation, source code, or web search.
- Check GPUI-Kit documentation before writing custom UI components to avoid re-implementing existing features.
- Use context7 mcp for fetch documentation.
- If mcp is not available, then fetch GPUI-Kit docs as raw Markdown by appending `.md` without a trailing slash (e.g. `https://gpui-kit.com/component/text-view.md`) instead of fetching HTML or scraping.
- Official GPUI-Kit documentation: https://gpui-kit.com/docs.md

## Rules

- Ask before installing any external libraries.
